# QuickTransfer 快传

[简体中文](README.md) | [English](README_EN.md)

QuickTransfer 是一个面向临时文件交付场景的全栈文件传输系统。它提供文件发送、取件码领取、文件收集、账号权益、流量管理和管理员设置，并将业务控制与文件存储拆分为独立边界。

## 主要能力

- 支持单文件、多文件和文件夹传输
- 支持访问链接、二维码和 10 位取件码
- 支持上传续传、下载 Range 请求和领取次数控制
- 支持游客、注册用户及多种 VIP 权益
- 支持永久上传流量、每日签到和兑换码
- 支持收集任务及提交者数据隔离
- 支持分片隔离、内容检查、原子发布和自动清理
- 支持管理员配置、用户运营、审计及外部服务状态管理

## 系统结构

```text
浏览器
  ├─ 页面、身份、任务和权益 ──> 控制面
  └─ 文件分片与下载字节 ─────> 存储面
                                  │
                                  └─ 签名状态回调 ──> 控制面
```

控制面负责页面、身份、任务元数据、权益、订单、审计和短时能力凭据；存储面负责分片、隔离、内容检查、对象发布、Range 下载和物理磁盘保护。文件主体不经过控制面转发。

## 账号策略

| 账号类型 | 单次任务总量 | 文件数 | 可选保留期 |
| --- | ---: | ---: | --- |
| 游客 | 100 MiB | 最多 100 个 | 1、12、24 小时 |
| 普通用户 | 2 GiB | 最多 100 个 | 1、12、24、72 小时 |
| 月卡/年卡 VIP | 10 GiB | 最多 1,000 个 | 1、12、24、72 小时 |
| 终身 VIP | 50 GiB | 最多 10,000 个 | 1、12、24、72 小时 |

任务总字节数与文件数量是两项独立限制。账号资源只记录剩余上传流量；下载不消耗流量。

## 构建

安装前端依赖：

```bash
npm ci
```

启动前端开发模式：

```bash
npm run dev
```

构建前端：

```bash
npm run build
```

构建全部 Go 程序：

```bash
npm run build:binaries
```

一次构建全部组件：

```bash
npm run build:all
```

## 配置原则

- 运行配置通过 `QT_*` 环境变量或外部受保护配置提供。
- 密码、会话密钥、邮件凭据、支付密钥和存储共享密钥不得写入源码。
- 外部邮件、验证码、内容检查和支付能力只有在配置完整并通过运行检查后才可启用。
- 未配置的外部服务应保持明确的不可用状态。

## 安全边界

- 密码使用强哈希保存，会话使用 HttpOnly Cookie，并对状态修改请求执行 CSRF 校验。
- 上传和下载使用短时、限范围能力凭据。
- 控制面与存储面之间的回调使用 HMAC、时间戳和重放保护。
- 上传文件经过隔离和内容检查后才会发布。
- 流量预留、结算、领取次数和兑换操作均由事务及唯一约束保护。
- 日志和浏览器响应不得包含密码、Cookie、验证码、密钥或完整兑换码。
